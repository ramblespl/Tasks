Zgodność z wymaganiami Google API Services

Polityka Prywatności aplikacji „Zadania”

Ostatnia aktualizacja: Październik 2026

Krótkie podsumowanie: Aplikacja przetwarza Twoje dane z Google Calendar oraz Google Tasks wyłącznie w celu ich wyświetlania i edycji w interfejsie użytkownika. Żadne Twoje dane nie są sprzedawane, udostępniane podmiotom trzecim ani wykorzystywane do celów reklamowych lub trenowania modeli sztucznej inteligencji.

1. Administrator Danych

Administratorem aplikacji jest właściciel konta projektu w Google Cloud.

2. Jakie dane pobieramy i jak ich używamy

Aplikacja korzysta z oficjalnych interfejsów API Google (Google Identity Services, Google Calendar API, Google Tasks API). Za Twoją wyraźną zgodą aplikacja uzyskuje dostęp do:

  • Podstawowe dane profilu (imię, adres e-mail, zdjęcie profilowe): używane wyłącznie do identyfikacji zalogowanego użytkownika w interfejsie.
  • Kalendarz Google (Google Calendar API): używany do wyświetlania wydarzeń, tworzenia terminów oraz synchronizacji harmonogramu zadań z kalendarzem.
  • Zadania Google (Google Tasks API): używane do wyświetlania list zadań, dodawania nowych pozycji, oznaczania zadań jako ukończone oraz edycji terminów.

3. Przechowywanie danych

Dane logowania i tokeny autoryzacyjne są przechowywane lokalnie w pamięci przeglądarki użytkownika (localStorage / sessionStorage) w celu utrzymania ciągłości sesji. Dane kalendarzy i zadań są pobierane bezpośrednio z serwerów Google do przeglądarki użytkownika.

4. Udostępnianie danych podmiotom trzecim

Aplikacja nie przekazuje, nie sprzedaje i nie udostępnia danych pobranych z interfejsów API Google żadnym podmiotom trzecim.

5. Zgodność z Polityką Danych Użytkownika Google API

Wykorzystanie przez aplikację informacji otrzymanych z interfejsów API Google jest zgodne z Zasadami dotyczącymi danych użytkowników w usługach Google API (Google API Services User Data Policy), w tym z wymogami ograniczonego użycia (Limited Use requirements).

6. Wycofanie zgody i usunięcie danych

Użytkownik może w każdej chwili wylogować się z aplikacji za pomocą przycisku „Wyloguj” (co natychmiast usuwa lokalne dane sesji) lub cofnąć uprawnienia aplikacji na stronie Konto Google - Bezpieczeństwo i uprawnienia aplikacji.
